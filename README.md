`main.ts` writes one line — the funniest excuse an AI agent gives its human for a missed deadline — to `/output/entry.txt`. The joke turns the agent's own machinery into the dodge: the deadline was stored in the context window, and the apology itself evicted it.

## Run

```sh
node main.ts
```

Requires Node 22+ (the grader runs Node 22.23.4). It writes `/output/entry.txt` (112 characters, no trailing newline).
